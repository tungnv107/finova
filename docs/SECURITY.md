# Finova — hướng dẫn bảo mật và kiểm soát phát hành

Các tài liệu kiểm soát chính: [Threat model](SECURITY_THREAT_MODEL.md), [authorization audit](AUTHORIZATION_AUDIT.md), [runbook](OPERATIONS_RUNBOOK.md) và [phase report](PHASE_REPORT.md). Mọi yêu cầu `/api/v1` dựa trên session/workspace server-side; các mutation kiểm tra Origin, input có validation, response tài chính dùng `no-store`. Journal/Posting thuộc sổ cái kép với ràng buộc dữ liệu và lệnh đối soát chỉ đọc `npm run db:reconcile`.

Để rà soát thay đổi mã nguồn, chạy `npm run security:routes`, `npm run security:audit`, `npm run test`, PostgreSQL integration trong database thử nghiệm, rồi kiểm tra HTTP negative cases. API guard audit là kiểm tra cấu trúc 85 tệp / 108 handler, **không thay thế** IDOR/session E2E hai người dùng. `FINOVA_CSP_ENFORCE=0` vẫn enforce object/base/frame/form protections; chính sách script đầy đủ ở Report-Only trong lúc nghiệm thu. Chỉ bật full enforcement sau khi đã xử lý CSP violations trong trình duyệt staging.

Quota OAuth/report/mutation dùng PostgreSQL; chỉ bật header IP đáng tin cậy nếu ingress ghi đè header client và chặn truy cập app trực tiếp. Cần WAF/edge rate limiting, TLS/HSTS, log redaction, giám sát quota/401/403/429/5xx, bảo vệ PostgreSQL khỏi Internet công khai và kiểm tra không cache dữ liệu tài chính tại CDN/service worker. Dữ liệu sao lưu phải mã hóa, có phân quyền và retention/offsite được phê duyệt.

Các việc **chưa nghiệm thu**: Google callback/session/logout thực tế, rà soát service IDOR đầy đủ, HTTPS/CSP enforcement/WAF, secret rotation, restore offsite, CI remote và tải multi-replica. Full-tree npm audit còn ngoại lệ 16 nút phụ thuộc Moderate *dev-only* từ cùng advisory minimatch đến 01/12/2026. Runtime audit đã về 0 sau cập nhật nhánh ExcelJS; xem [báo cáo 31/10/2026](SYSTEM_AUDIT_2026-10-31.md) và kết quả kiểm tra mới nhất. Không công bố ứng dụng là production-ready trước khi các gate này đạt.
